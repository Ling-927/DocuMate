⚙ Konfigurasi Cisco Router (IOS Commands)
! ═══════════════════════════════════════ ! CISCO 1941 ROUTER – MAKMAL RANGKAIAN ! ═══════════════════════════════════════ enable configure terminal ! Nama peranti hostname Router-Makmal ! Kata laluan enable enable secret Cisco@Lab2024 service password-encryption ! Antara muka LAN (disambung ke switch) interface FastEthernet0/0 description LAN-Makmal-Rangkaian ip address 192.168.1.254 255.255.255.0 no shutdown ! Antara muka WAN / ISP interface FastEthernet0/1 description WAN-ISP-Link ip address dhcp no shutdown ! NAT – Pelajar & Pengajar ke Internet ip nat inside source list 1 interface FastEthernet0/1 overload access-list 1 permit 192.168.1.0 0.0.0.255 interface FastEthernet0/0 ip nat inside interface FastEthernet0/1 ip nat outside ! DNS & Default Route ip domain-lookup ip name-server 8.8.8.8 8.8.4.4 ip route 0.0.0.0 0.0.0.0 FastEthernet0/1 ! Banner MOTD banner motd #MAKMAL RANGKAIAN – AKSES DIHADKAN# end write memory
⚙ Konfigurasi Cisco Switch (VLAN + Trunking)
! ════════════════════════════════════════ ! CISCO CATALYST 2960 – SWITCH MAKMAL ! ════════════════════════════════════════ enable configure terminal hostname SW-Makmal-01 enable secret Cisco@Lab2024 service password-encryption ! Cipta VLAN vlan 10 name PELAJAR vlan 20 name PENGAJAR vlan 99 name PENGURUSAN ! Port pelajar (Fa0/1–Fa0/23) interface range FastEthernet0/1 - 23 switchport mode access switchport access vlan 10 spanning-tree portfast no shutdown ! Port pengajar (Fa0/24) interface FastEthernet0/24 switchport mode access switchport access vlan 20 spanning-tree portfast no shutdown ! Uplink ke Router (GigabitEthernet0/1) interface GigabitEthernet0/1 description Uplink-ke-Router-Makmal switchport mode trunk switchport trunk allowed vlan 10,20,99 no shutdown ! SVI Pengurusan interface vlan 99 ip address 192.168.99.1 255.255.255.0 no shutdown ip default-gateway 192.168.99.254 ! Matikan port yang tidak digunakan interface range FastEthernet0/25 - 24 shutdown end write memory

🌐 Arahan Simulasi Cisco Packet Tracer

Langkah Bina Topologi dalam Packet Tracer:

  1. Buka Cisco Packet Tracer → New File
  2. Tambah Cisco 1941 Router dari Device Box
  3. Tambah Cisco 2960-24TT Switch
  4. Tambah 26× Generic PC (25 pelajar + 1 pengajar)
  5. Sambung Router Fa0/0 → Switch GigabitEthernet0/1 (kabel Copper Straight-Through)
  6. Sambung setiap PC ke Switch Fa0/1–Fa0/25 (kabel Copper Straight-Through)
  7. Klik Router → CLI → masukkan konfigurasi IOS di atas
  8. Klik Switch → CLI → masukkan konfigurasi VLAN di atas
  9. Set IP setiap PC: Desktop → IP Configuration → Static
  10. Uji dengan ping 192.168.1.254 dari mana-mana PC
  11. Uji komunikasi PC Pelajar → PC Pengajar (cross-VLAN melalui router)
  12. Simpan fail sebagai Makmal-Rangkaian.pkt

Tetapan IP Statik setiap PC (Desktop → IP Config):

! PC Pelajar (contoh PC-01) IP Address : 192.168.1.10 Subnet Mask : 255.255.255.0 Default GW : 192.168.1.254 DNS Server : 8.8.8.8 ! PC Pengajar IP Address : 192.168.1.1 Subnet Mask : 255.255.255.0 Default GW : 192.168.1.254 DNS Server : 8.8.8.8 ! Ujian Sambungan (CLI dari PC) C:\> ping 192.168.1.254 (ping gateway) C:\> ping 192.168.1.1 (PC pengajar) C:\> ping 192.168.1.11 (PC pelajar lain) C:\> tracert 192.168.1.254 (trace route)
Cadangan Packet Tracer: Guna Simulation Mode untuk melihat perjalanan paket ICMP secara visual dari satu PC ke PC lain melalui switch dan router.
